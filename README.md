# NEW AI

Eigener browserbasierter Assistant-Core.

- lokaler Chat
- lokales Memory
- Rechner
- Uhrzeit/Datum
- Notizen
- keine API-Schlüssel
- keine Cloud-Abhängigkeit für den Core

Hinweis: Dies ist noch kein großes trainiertes Sprachmodell. Für freie generative Antworten, Web-Recherche und Bildgenerierung müssen später passende Modelle bzw. Dienste angebunden werden.
