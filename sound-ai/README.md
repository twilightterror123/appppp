# SOUND AI

Sound-only AI Studio für lokale Audio-Bearbeitung im Browser.

## Funktionen

Audio-Datei laden, automatische Analyse, Auto-Mix, EQ, Kompressor, Sättigung, Limiter, Stereo, Reverb, Echo, Speed, Pitch, Start/Ende-Schnitt, leise Stellen-Erkennung, A/B-Wiedergabe, Version-Historie, WAV-Export und ein Chat für natürliche Sound-Befehle.

Die Verarbeitung passiert direkt im Browser. Die Web Audio API stellt Audio-Nodes wie Filter, Gain, Compressor, Delay, Convolver und Waveshaper bereit; OfflineAudioContext kann die Mischung schnell in einen AudioBuffer rendern.
